# Sprint 1 route map

This document lists only the four routes planned for Sprint 1 of the Hockey Ops Player Directory. It is a map, not an implementation of the page bodies.

## Sprint 1 routes

| URL path | Kind | Purpose | Planned route file | Bookmarkable |
| --- | --- | --- | --- | --- |
| `/` | static | Home page for the directory | `src/routes/index.tsx` | Yes |
| `/players` | static | List of players | `src/routes/players/index.tsx` | Yes |
| `/players/$playerId` | dynamic | One player's detail page | `src/routes/players/$playerId.tsx` | Yes |
| `/games` | static | List of games | `src/routes/games.tsx` | Yes |

## Dynamic player URLs

`$playerId` is a **dynamic path parameter**. The `$` in the route file name tells TanStack Router that this part of the URL is a value, not a fixed word.

A URL such as `/players/42` means “show the player whose id is 42.” Because that id lives in the address bar, the page can be bookmarked, copied, and opened again later. The same idea applies to any other player id, for example `/players/7`.

Those player files are not created in this step. The table above is the planned location so later work stays consistent with this map.

## How the four routes relate

The root layout wraps every page. Home, players, and games sit under that layout. The player detail page sits under the players path because its URL starts with `/players/`.

```text
src/routes/__root.tsx          shared layout for every page
├── /                          src/routes/index.tsx
├── /players                   src/routes/players/index.tsx
│   └── /players/$playerId     src/routes/players/$playerId.tsx
└── /games                     src/routes/games.tsx
```

## Role of `src/routes/__root.tsx`

`__root.tsx` is the shared document shell. It is not a page users navigate to by itself. It provides the HTML document, the “Hockey Ops Directory” header, and the place where the current child route is rendered. Home, players, player detail, and games all appear inside this shell.

## Role of `src/routeTree.gen.ts`

`src/routeTree.gen.ts` is generated by TanStack Router from the files in `src/routes/`. The app reads this file so it knows which URLs exist and how they nest. Do not edit it by hand as a lasting fix. After route files change, regenerate it with the project workflow (`npm run generate-routes`, or by running `npm run dev`, which also keeps the tree in sync).

- [ ] `/players/$playerId` is documented as a dynamic path, not a static folder name.
- [ ] A URL such as `/players/42` is understood as one specific player.
- [ ] Player detail URLs are bookmarkable and shareable because the player id is part of the path.
- [ ] Invalid or missing player pages are a later concern; this step only confirms the URL design supports bookmarks.
- [ ] `src/routes/__root.tsx` is the shared shell, not a player or games page.
- [ ] `src/routeTree.gen.ts` is generated, not hand-maintained.
